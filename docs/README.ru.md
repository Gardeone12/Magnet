# Magnet

Язык: [English](../README.md) | Русский

Magnit — Paper-плагин для Minecraft, который добавляет предмет-магнит. Когда игрок держит магнит в основной или второй руке, рядом лежащие металлические предметы притягиваются к игроку.

## Возможности

- Команда `/magnet` выдаёт игроку предмет-магнит.
- Магнит работает из основной руки и из off-hand.
- Железные предметы притягиваются с полной силой.
- Незеритовые предметы притягиваются слабее.
- Магнит помечается через `PersistentDataContainer`, поэтому плагин отличает его от обычного аметистового осколка.
- Встроенные сообщения плагина поддерживают английский язык как основной и русский язык как вторичную локализацию.

## Требования

- Minecraft / Paper: `1.21.11`
- Java: `21`
- Kotlin JVM: `2.4.0-RC`

## Команды

| Команда | Описание |
| --- | --- |
| `/magnet` | Выдать игроку предмет-магнит |

Для команды сейчас не настроено отдельное разрешение.

## Как работает

Каждые 2 тика плагин проверяет игроков онлайн. Если игрок держит магнит, плагин ищет выпавшие предметы в радиусе 7 блоков и притягивает поддерживаемые материалы к игроку.

С полной силой притягиваются:

- железные слитки, самородки, блоки, сырое железо и железная руда;
- железные инструменты, оружие и броня;
- кольчужная броня;
- наковальни, железные решётки, железные двери и люки;
- рельсы и вагонетки;
- ведра, ножницы, компасы и похожие металлические предметы.

С пониженной силой притягиваются:

- незеритовые слитки, обломки и блоки;
- незеритовые инструменты, оружие и броня.

## Сборка

Если Gradle установлен в системе:

```powershell
gradle build
```

Если в проекте есть файлы Gradle Wrapper:

```powershell
.\gradlew.bat build
```

Готовый `.jar` появится в папке:

```text
build/libs/
```

## Установка

1. Соберите плагин.
2. Скопируйте `.jar` из `build/libs/` в папку `plugins` Paper-сервера.
3. Запустите или перезапустите сервер.
4. В игре выполните команду `/magnet`.

## Локальный тестовый сервер

Проект использует `xyz.jpenilla.run-paper`, поэтому локальный Paper-сервер можно запустить командой:

```powershell
gradle runServer
```

Если в проекте есть файлы Gradle Wrapper:

```powershell
.\gradlew.bat runServer
```
